# Revanor website — versão 3.2

Site estático bilíngue preparado para publicação no GitHub Pages. Esta versão apresenta a Revanor como consultoria empresarial com duas frentes independentes:

1. Executive Advisory;
2. IA Aplicada aos Negócios.

## Estrutura

- `index.html`: versão em português.
- `en/index.html`: versão em inglês.
- `assets/styles.css`: estilos compartilhados e navegação responsiva.
- `assets/site.js`: menu móvel, preservação da seção na troca de idioma e destaque da navegação.
- `assets/`: imagens otimizadas, favicon e imagens de compartilhamento.
- `robots.txt` e `sitemap.xml`: indexação e SEO bilíngue.
- `CNAME`: domínio personalizado do GitHub Pages.

## Publicação

Substitua o conteúdo publicado do repositório pelos arquivos desta pasta, preservando a mesma estrutura de diretórios. O domínio configurado é `revanor.com.br`.

Antes de publicar, revise apenas:

1. o endereço de contato `contato@revanor.com.br`;
2. a configuração de domínio do GitHub Pages.

Não há dependências, processo de build, cookies, analytics ou formulário externo. As duas frentes possuem seções e links de contato próprios.
